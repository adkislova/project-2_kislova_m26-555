Управление таблицами.

Команда create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> создает таблицу
Команда list_tables показывает список всех таблиц
Команда drop_table удаляет таблицу
Команда exit позволяет выйти из программы
Команда help выводит справочная информация

CRUD-операции.

Команда insert into <имя_таблицы> values (<значение1>, <значение2>, ...) создает запись.
Команда select from <имя_таблицы> where <столбец> = <значение> читает записи по условию.
Команда select from <имя_таблицы> читает все записи.
Команда update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия> обновляет запись.
Команда delete from <имя_таблицы> where <столбец> = <значение> удаляет запись.
Команда info <имя_таблицы> выводит информацию о таблице.
Команда exit позволяет выйти из программы
Команда help выводит справочная информация
