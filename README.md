# primitive_db — примитивная база данных


## Установка и запуск

| Действие | Команда |
| --- | --- |
| установка | `make install` / `uv sync` |
| проверка стиля | `make lint` / `uv run ruff check .` |
| запуск | `make run` / `uv run database` / `database` |

## 1. Управление таблицами

| Команда | Описание |
| --- | --- |
| `create_table <имя> <столбец:тип> ...` | создаёт таблицу; столбец `ID` добавляется автоматически первым |
| `list_tables` | показывает список всех таблиц |
| `drop_table <имя>` | удаляет таблицу (с запросом подтверждения) |

Демонстрация управления таблицами: https://asciinema.org/a/dzCO5M0NqEvBJjHP

## 2. CRUD-операции

| Команда | Описание |
| --- | --- |
| `insert into <имя> values (<знач1>, <знач2>, ...)` | создаёт запись; `ID` генерируется автоматически, все поля обязательны |
| `select from <имя>` | читает все записи |
| `select from <имя> where <поле> = <значение>` | читает записи по условию (условия можно объединять через `AND`) |
| `update <имя> set <поле> = <значение> where <поле> = <значение>` | обновляет записи по условию |
| `delete from <имя> where <поле> = <значение>` | удаляет записи по условию (с запросом подтверждения) |
| `info <имя>` | схема и количество записей |
| `exit` | выход из программы |
| `help` |  справка |

Демонстрация CRUD-операций: https://asciinema.org/a/ihj2xdRbBK6g4gWU

## 3. Декораторы и замыкания

| Механизм | Что делает |
| --- | --- |
| `handle_db_errors` | централизованно перехватывает ошибки (нет таблицы/столбца, неверный тип) и выводит сообщение |
| `confirm_action` | перед опасными операциями (`delete`, `drop_table`) запрашивает подтверждение `[y/n]`; без `y` операция отменяется |
| `log_time` | замеряет и выводит время выполнения `select` и `insert` |
| `create_cacher()` | замыкание-кэш: повторные одинаковые `select` отдаются мгновенно; кэш сбрасывается при изменении данных |

Демонстрация декораторов и замыканий: https://asciinema.org/a/uH6wcRWgBD4rmGf4

### Пример

```text
>>> Введите команду: delete from products where ID = 2
Вы уверены, что хотите выполнить "удаление записей"? [y/n]: y
Запись с ID=2 успешно удалена из таблица "products".

>>> Введите команду: select from products
Функция select выполнилась за 0.001 секунд.
+----+--------------------+-------+----------+
| ID |       title        | price | in_stock |
+----+--------------------+-------+----------+
| 1  | Пушкин А.С., том 1 |  500  |   True   |
+----+--------------------+-------+----------+

>>> Введите команду: select from products   # повторный запрос — из кэша
+----+--------------------+-------+----------+
| ID |       title        | price | in_stock |
+----+--------------------+-------+----------+
```

Повторный одинаковый `select` не печатает строку тайминга — результат отдан из кэша.

## 4. Хранение данных

- метаданные таблиц (схемы): `src/primitive_db/db_meta.json`
- данные таблиц: `src/primitive_db/data/<имя_таблицы>.json`
